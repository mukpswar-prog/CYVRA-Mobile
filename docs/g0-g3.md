rejects attaching a Git `source` (`8000069`). Convert it in the dashboard only:

1. Open **`cyvra-mobile`** (not `cyvra-www`) → Settings → Builds & deployments.
2. Connect Git: repo **`mukpswar-prog/CYVRA-Mobile`**.
3. Production branch: **`main`**. Root directory **empty**.
4. Build command and output are already set on the project (see
   [codespaces-pages.md](./codespaces-pages.md)).
5. Env `VITE_API_URL=https://cyvra-mobile-api.mukpswar.workers.dev` is already
   set on production and preview. No `DATABASE_URL` on Pages.

Until Git is connected, a Direct Upload to **`cyvra-mobile` only** is the
preview path. Never `wrangler pages deploy` to `cyvra-www`.
