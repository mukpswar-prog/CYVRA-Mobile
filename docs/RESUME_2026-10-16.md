### 3.3 CRC32 — settled in principle

CRC32 is a checksum the packer computes to detect **damage**. It is not an identity
check, and **the manifest publishes no CRC32 at all — SHA-256 only.** There is
therefore nothing in the project for a CRC32 to match.

- The screenshot's CRC32 column read **7CCF4970**; the Chief Engineer wrote
  **7CCF4870**. One digit differs. **The source of each has never been confirmed.**
- The value that matters:
  **`sha256 = 01921cdf270ad163fb126bdcf130dc6f9a8666e8bd7cdd6a07e63b06b321d6eb`**,
  `sizeBytes = 555388386`.
- How to check a download:
  `Get-FileHash -Algorithm SHA256 "<path>"`
