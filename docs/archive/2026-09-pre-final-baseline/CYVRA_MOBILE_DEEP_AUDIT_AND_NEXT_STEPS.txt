5. SECURITY & COMPLIANCE VERIFICATION (12 INVARIANTS)
================================================================================
The codebase was verified against the 12 Absolute Invariants of CYVRA Mobile:
- Zero private signing keys in client code, configuration, or git tracking (SEC-001).
- Zero Razorpay / Stripe payment gateway secrets in desktop client (SEC-002).
- Zero administrative authority or backdoor tokens in client code (SEC-003).
- Strict prohibition against synthetic or assumed IMEI/serial identifiers (SEC-004).
- Parameterized, whitelisted ADB commands with metacharacter blocking (SEC-005).
- Ed25519 signature enforcement for delta update packages (SEC-006).
- Server-authoritative cryptographic scan entitlement verification (SEC-007).
- Pinned and bundled Google Platform-Tools adb v35.0.2 (SEC-008).
- Mandatory Two-Step Confirmation Purge Barrier with typed serial check (SEC-009).
- Strict offline grace boundaries: Destructive purges locked to online state (SEC-010).
- Multi-OEM hardware warranty and Knox attestation boundary respect (SEC-011).
- Tamper-evident SHA-256 digital seals on all certificates (SEC-012).

6. ROADMAP: WHAT TO DO NEXT (OPERATIONAL & HARDWARE DEPLOYMENT)
================================================================================
With the complete software engineering baseline frozen and verified, the next
steps transition from code construction to physical operational testing and release:

PHASE 1: Pull & Verify Baseline on Operator Laptop:
1. In Git Bash on the Windows development laptop:
   `cd /c/Users/User/StudioProjects/CYVRA-Mobile`
   `git pull`
   `cd apps/android`
   `./gradlew.bat --stop`
   `./gradlew.bat -Dorg.gradle.java.home="C:/Program Files/Java/jdk-21" :core:test :host:test`
   Verify `BUILD SUCCESSFUL` across all 32 unit test classes.

PHASE 2: Build Native Windows Executable (.exe Installer):
1. Execute the Tauri/NSIS bundler script:
   `pnpm --filter @cyvra/web build`
2. Run packaging harness to bundle `cyvra-workstation.exe` with `platform-tools\adb.exe`
   and `WebView2Loader.dll` into `CYVRA-Mobile-Setup-v3.2.2-x64.exe`.
3. Submit binary to DigiCert Authenticode signing service.
4. Upload final setup binary to distribution server (`downloads/windows/`).

PHASE 3: Physical Hardware Testing with Live Samsung & Motorola Devices:
1. Connect physical Motorola Moto G54 (Live test baseline):
   - Verify USB hotplug detection on Windows.
   - Run Advanced Diagnostic: Verify battery charge nodes, storage, and build props.
   - Test AI Physical 6-view camera station and display test patterns.
2. Connect owned Samsung Galaxy test unit (when arrived):
   - Verify Samsung Knox warranty bit (0x0).
   - Verify `sec_bat_health_node` battery telemetry.
   - Execute controlled 2-step data purge and post-reboot reconnect verification.
   - Export final NIST SP 800-88 Rev. 2 Sanitization Certificate.

PHASE 4: Production Cloudflare & Database Staging:
1. Execute Neon PostgreSQL migration (`scripts/migrate-neon.sh`) to lock
   the `entitlement_revisions` and `scan_transactions` tables.
2. Deploy Cloudflare Worker API preview (`scripts/deploy-api-preview.sh`).
3. Conduct end-to-end commercial checkout test on https://cyvoriq.co.in/ with
   Option B admin approval gate.
