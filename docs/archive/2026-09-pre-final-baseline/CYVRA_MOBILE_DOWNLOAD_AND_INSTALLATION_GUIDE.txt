1. ARCHITECTURAL OVERVIEW: WHY A WINDOWS DESKTOP (.EXE) APPLICATION?
================================================================================
When users sign in to https://cyvoriq.co.in/, they access the cloud-backed
commercial and licensing workspace. While this web portal allows account
management, plan upgrades, scan entitlement auditing, and report archive review,
a web browser CANNOT directly interact with low-level hardware on physical
Android smartphones.

Web browsers execute in isolated sandboxes for security:
- Web browsers cannot bind raw USB endpoints or communicate with device bootloaders.
- Web browsers cannot execute Android Debug Bridge (ADB) daemon sockets on port 5037.
- Web browsers cannot send recovery commands, trigger platform factory resets, or
  query low-level battery charge controller nodes (`/sys/class/power_supply`).
- Web browsers cannot automate controlled display testing patterns during screen AI inspection.

THEREFORE, CYVRA MOBILE IS DELIVERED AS A NATIVE 64-BIT WINDOWS DESKTOP APPLICATION
(.EXE SETUP INSTALLER).

The Desktop Architecture comprises:
1. Native Windows Host Runner: Orchestrates local device communication, background
   ADB daemons, USB hotplug detection, and file system integrity.
2. Controlled Google Platform-Tools (adb.exe v35.0.2): Pinned internally so that the
   customer machine never depends on arbitrary or broken ADB binaries in Windows PATH.
3. Microsoft Edge WebView2 Evergreen Shell: Renders the fluid, hardware-accelerated
   Customer Desktop Workstation user interface natively inside a Windows desktop window.
4. Cryptographic Validation Subsystem: Validates licenses offline and online with
   Ed25519 signatures and SHA-256 canonical hashing.

2. SYSTEM REQUIREMENTS & PREREQUISITES
================================================================================
A. Hardware Requirements:
   - Processor: Intel Core i3 / AMD Ryzen 3 (or higher), 64-bit x86_64 architecture.
   - Memory (RAM): Minimum 4 GB RAM (8 GB recommended for simultaneous AI inspection).
   - Storage Space: Minimum 500 MB free storage on the OS drive (C: drive recommended).
   - Ports: Minimum 1 available USB 2.0 / 3.0 / USB-C port with high-speed data transfer.
     (Note: Low-power passive USB hubs or charging-only cables are strictly prohibited).

B. Operating System Requirements:
   - Windows 10 64-bit (Build 1803 or later: 1909, 20H2, 21H1, 21H2, 22H2).
   - Windows 11 64-bit (All builds: 21H2, 22H2, 23H2, 24H2).
   - Windows Server 2019 / 2022 (Standard / Datacenter 64-bit with Desktop Experience).

C. Software Runtime Dependencies:
   - Microsoft Edge WebView2 Runtime: Pre-installed by default on Windows 10/11.
     If absent, the CYVRA bootstrapper downloads and configures it automatically.
   - Microsoft Visual C++ 2015–2022 Redistributable (x64): Bundled in installer.
   - Java / Android Studio: NOT REQUIRED. Technicians do not need to install
     Android Studio, JDK, Gradle, or SDK Manager.

4. CODE SIGNING & AUTHENTICODE INTEGRITY VERIFICATION
================================================================================
Every official release of CYVRA Mobile is cryptographically signed using a
publicly trusted Microsoft Authenticode Code Signing Certificate.

To verify the installer before running:
1. Locate `CYVRA-Mobile-Setup-v3.2.2-x64.exe` in Windows File Explorer.
2. Right-click the file and select "Properties".
3. Click the "Digital Signatures" tab.
4. Select the signature in the list and click "Details".
5. Verify the following parameters:
   - Signer Name: "CYVORIQ Solutions Private Limited"
   - Digest Algorithm: sha256
   - Timestamp Authority: DigiCert Timestamp Responder 2026
   - Status: "This digital signature is OK."

SHA-256 Checksum Verification via PowerShell:
Run the following command in Windows PowerShell:
   Get-FileHash -Algorithm SHA256 "CYVRA-Mobile-Setup-v3.2.2-x64.exe"

Expected Checksum:
9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

If the hash does not match, delete the file immediately and re-download.

 ├── cyvra-workstation.exe             (Native Windows 64-bit launcher)

 ├── platform-tools\                   (Controlled Google Platform-Tools bundle)

 │    └── AdbWinUsbApi.dll             (WinUSB driver binding)
 ├── config\

`%LOCALAPPDATA%\CYVRA Mobile\`
 ├── license\

 │    └── offline_grace.json           (24-hour offline grace record & hash)

9. FIREWALL, ANTIVIRUS & DRIVER CONFIGURATION
================================================================================
A. Local Loopback Port 5037 (ADB Daemon):
   - CYVRA Mobile communicates with `platform-tools\adb.exe` via TCP loopback
     address `127.0.0.1:5037`.
   - Ensure local host firewalls (Windows Defender, Symantec, CrowdStrike) allow
     internal loopback communication on port 5037. No external internet ports
     are opened by the ADB daemon.

B. Outbound HTTPS Licensing Traffic:
   - Protocol: HTTPS (Port 443 only).
   - Domain Whitelist: `*.cyvoriq.co.in`, `api.cyvoriq.co.in`.

C. OEM USB Drivers:
   - Windows 10/11 includes universal WinUSB drivers for standard Android ADB.
   - For specific manufacturers (e.g., Samsung Galaxy), install the official
     Samsung Android USB Driver if Windows Device Manager shows an exclamation mark:
     `SAMSUNG_USB_Driver_for_Mobile_Phones.exe`.

10. TROUBLESHOOTING INSTALLATION & RUNTIME ERRORS
================================================================================
Symptom 1: SmartScreen prompt "Windows protected your PC".
Resolution: Click "More info", verify the publisher states "CYVORIQ Solutions
Private Limited", and click "Run anyway". As new releases build SmartScreen
reputation, this prompt will disappear.

Symptom 2: "Microsoft Edge WebView2 Runtime missing".
Resolution: The installer normally downloads WebView2 Evergreen automatically.
If offline, manually install the Evergreen Standalone Installer (x64) from
Microsoft's official distribution portal.

Symptom 3: ADB port 5037 collision.
Resolution: If another software package (e.g., old Android Studio or third-party
phone manager) has locked port 5037, open Command Prompt as Administrator and run:
   taskkill /F /IM adb.exe
Then re-launch CYVRA Mobile. The application will start its controlled adb instance.

Symptom 4: Device connected via USB is not detected.
Resolution:
1. Ensure the USB cable supports high-speed data (not charging-only).
2. On the Android phone: Go to Settings -> About Phone -> Tap "Build Number" 7 times.
3. Open Settings -> System / Developer Options -> Enable "USB Debugging".
4. Look at the phone screen; when the prompt appears:
   "Allow USB debugging? ... Fingerprint: ...",
   Check "Always allow from this computer" and tap "Allow".
