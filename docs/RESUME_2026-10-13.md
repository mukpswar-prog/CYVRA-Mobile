## 4. The achievement the Chief Engineer asked to be remembered

> **CYVRA remotely wiped a real Android device with a factory reset.**

Method: `adb shell am broadcast -n com.cyvra.sanitization/.SanitizationBroadcastReceiver
-p com.cyvra.sanitization -a com.cyvra.sanitization.WIPE` →
`DevicePolicyManager.wipeData(0)`.

Measured result (counts only, no identifiers — `docs/CYVRA_FACTORY_RESET_PROOF_2026-10-12.md`):

| Metric | Before | After |
|---|---:|---:|
| Total installed packages | 363 | 333 |
| Third-party packages | 40 | 4 |
| CYVRA packages present | 2 | 0 |
| **CYVRA Device Owner references** | **4** | **0** |
| Contact rows | 294 | 1 |
| Media rows | 288 | 20 |
| Accounts | 1 | 0 |

The Device Owner line is decisive: five removal methods all refused that
morning, so the only remaining path was a factory reset, and it is now gone.
That follows from a measured negative result, not from an inference.

Two defects were found *by running it*: an implicit broadcast is silently
inoperative on Android 8.0+ while printing `result=0`, and `android:testOnly`
is a grant-time precondition that cannot be retrofitted. Both fixed and
recorded.

**Its five stated weaknesses stand** (§5 of the proof): one device only; **not
agent-less**; purge verified but *verification* unratified; two post-reset
observations the assistant did not make and does not explain; the human step
untested above one device.
