     Created: you make a long random string (password manager).
     Stored: wrangler secret put ADMIN_API_TOKEN
             on Worker cyvra-mobile-api only.
     If missing after G7 deploy: live /admin/serials returns 503.
     If you never put it: live /admin/serials stays 404 (old Worker) or 503.

  Command order meaning:
    First line  = unlock wrangler (use existing cyvra-mobile token).
    Second line = wrangler, now unlocked, uploads a NEW random ops password
                  into the Worker. You type that NEW string at the secret prompt,
                  not the Cloudflare token again.
